# Contributing to Numos
Thanks for contributing to Numos. A few things to note:
- Make sure to follow the `.editorconfig`. ReSharper rules are used extensively, so pay attention to your IDE's warnings and the surrounding code style.
- Document your code well. You may know your code, but others won't, so be sure to clue people in as to what you're doing and why you're doing what you're doing.
- In your PR, be sure to explain your changes well and why you made the changes. Mathematical deriverations in LaTeX are appreciated.
- You're responsible for the code you write.
